# 📖 1. What is Data?

## Definition

Data is a collection of raw facts, figures, observations, or values that have little meaning on their own. Once data is processed and organized, it becomes useful information.

### Examples

- Customer Name
- Policy Number
- Salary
- Age
- Product Name
- Order ID

### Example

| Name | Age | Salary |
|------|----:|--------:|
| Rahul | 25 | 45000 |
| Priya | 27 | 52000 |

The above table contains **raw data**.

---

# 📖 2. What is Information?

## Definition

Information is processed, organized, and meaningful data that helps people make decisions.

### Example

### Raw Data

| Employee | Salary |
|-----------|--------:|
| Rahul | 45000 |
| Priya | 52000 |
| Arun | 48000 |

### Information

Average Salary = **48333**

Now the data provides useful business insight.

---

# 📖 Difference between Data and Information

| Data | Information |
|------|-------------|
| Raw facts | Processed data |
| No meaning by itself | Meaningful |
| Input | Output |
| Used for processing | Used for decision-making |

---

# 📖 3. Types of Data

## Structured Data

Data stored in rows and columns.

Examples:

- Customer Table
- Employee Table
- Sales Table

Stored in:

- PostgreSQL
- MySQL
- Oracle
- SQL Server

---

## Semi-Structured Data

Data that has some organization but not a fixed table structure.

Examples:

- JSON
- XML

---

## Unstructured Data

Data without a predefined structure.

Examples:

- Images
- Videos
- Audio
- Emails
- PDF Documents

---

# 📖 4. What is a Database?

A database is an organized collection of related data stored electronically so it can be easily accessed, updated, and managed.

Instead of storing millions of records in Excel, companies use databases because they are:

- Faster
- More secure
- Easy to search
- Easy to update
- Can store huge amounts of data

### Example

An online shopping application stores:

- Customers
- Products
- Orders
- Payments

All these records are stored inside a database.

---

# 📖 5. Types of Databases

## Relational Database (RDBMS)

Stores data in tables (rows and columns).

Examples:

- PostgreSQL
- MySQL
- Oracle
- SQL Server

Uses SQL to manage data.

---

## NoSQL Database

Stores data in flexible formats.

Examples:

- MongoDB
- Cassandra
- Redis

Commonly used for:

- Social Media
- IoT
- Real-time Applications
- Big Data

---

# 📖 6. What is SQL?

SQL stands for **Structured Query Language**.

It is the standard language used to communicate with relational databases.

Using SQL we can:

- Retrieve data
- Insert data
- Update data
- Delete data
- Create databases
- Create tables
- Analyze data

Example:

```sql
SELECT * FROM Employee;
```

---

# 📖 7. What is Data Engineering?

Data Engineering is the process of designing, building, and maintaining systems that collect, clean, transform, store, and deliver data for analytics and business decision-making.

A Data Engineer builds data pipelines that move data from different sources into a central storage system such as a Data Warehouse or Data Lake.

### Responsibilities of a Data Engineer

- Write SQL queries
- Build ETL/ELT pipelines
- Develop Python automation
- Process large datasets
- Build Data Warehouses
- Ensure Data Quality
- Optimize performance

---

# 📖 8. Difference Between Roles

| Data Engineer | Data Analyst | Data Scientist |
|--------------|--------------|----------------|
| Builds data pipelines | Analyzes business data | Builds Machine Learning models |
| Creates ETL processes | Creates dashboards | Predicts future trends |
| Works with SQL, Python, Spark | Works with SQL, Excel, Power BI | Works with Python, ML, Statistics |
| Focuses on data infrastructure | Focuses on business insights | Focuses on AI & prediction |
